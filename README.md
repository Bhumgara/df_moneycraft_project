# MoneyCraft channel analysis
Exploratory data analysis of marketing ROI for MoneyCraft's £1.4m packaged account campaigns. Delivering clear budget recommendations backed by core data insights. Built for Digital Futures' Frontier AI Programme.

## Project Overview
MoneyCraft Financial Services, a national retail bank, invested **£1.4m** across **six** distinct promotional channels to acquire customers for their **four** tiered packaged current accounts. 

This repository contains an end-to-end data analysis workflow designed to identify high-performing acquisition channels and isolate ineffective marketing spend, providing actionable insights for future budget allocation.
